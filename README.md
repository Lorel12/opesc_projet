# 📊 Prévisions Économiques Cameroun — Web App

Une application web interactive développée avec **Flask** pour collecter, analyser et prédire des indicateurs économiques au Cameroun. Le projet combine scraping web, visualisation de données, intelligence artificielle et outils de recherche textuelle.

## 🧰 Technologies utilisées

- **Python / Flask** : Backend web
- **HTML / CSS** : Frontend responsive
- **JavaScript** : Interaction utilisateur
- **BeautifulSoup / Requests** : Web scraping
- **Pandas / NumPy / scikit-learn** : Analyse et prévisions
- **mongodb** : Base de données 
- **Jinja2** : Templates HTML dynamiques

## ⚙️ Fonctionnalités principales

- 🔐 Authentification des utilisateurs (inscription / connexion sécurisée)
- 🌐 Scraping d’articles économiques depuis plusieurs sources camerounaises
- 🧠 Moteur d’analyse sémantique et sentimentale des actualités
- 📈 Module de prévision économique 
- 🔎 Recherche d’articles par mots-clés et filtre par **année de publication**
- 📬 Formulaire de contact et section actualités économiques
